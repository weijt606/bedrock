        Who Owns Your Kitchen — prototype, TechEurope Barcelona.

        Every ownership fact comes from the Cala API (knowledge/query, knowledge/search). Each layer shows the exact query that produced it and how long it took. Cold queries take 16–75 seconds; once a query has run, it returns in about half a second forever, which is why the dig speeds up as more people play. Photograph mode uses vision to read the brand name off the label and nothing else — no fact on this page is written by a language model.
